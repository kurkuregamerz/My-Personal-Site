## 🌟 Features

* **Modern & Responsive Design:** Clean, eye-catching grid overlay layout optimized for all screen sizes.
* **Animated UI**: Smooth, and fast UI animations.
* **4 Designated Pages**: 4 pages including home, about, services and contact.
* **Interactive Navigation:** Smooth navigation links to Home, About, Services, and Contact sections.
* **Developer Profile:** Highlighted bio and social links (Instagram/GitHub/Contact details).
* **Services Section:** Clear overview of front-end development capabilities and skills.
  

## 🛠️ Tech Stack

* **HTML5** - Page structure and semantically organized content
* **CSS3** - Custom layouts, styling, grids, and responsive design
* **Vanilla JavaScript** - Interactivity and smooth navigation
